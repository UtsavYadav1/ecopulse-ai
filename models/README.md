# Models Directory

This directory stores trained model artifacts generated by `python src/train.py`.

## Files Generated After Training

| File | Description |
|------|-------------|
| `final_model.joblib` | Serialised best-performing trained model |
| `feature_columns.joblib` | Ordered list of feature column names |
| `metrics.json` | Model comparison metrics and anomaly summary |
| `anomaly_threshold.json` | Anomaly detection threshold parameters |
| `anomaly_results.csv` | Full test-set predictions with anomaly flags |

## Regenerating Models

```bash
python src/train.py
```

This will:
- Download the dataset (if not already cached)
- Preprocess and engineer features
- Train Linear Regression and Random Forest models
- Evaluate both on the chronological test split
- Select and save the best model
- Generate all evaluation plots

## Notes

- Model files are included in version control by default to allow the Flask app to run without retraining.
- To exclude them (e.g. if models are large), uncomment the relevant lines in `.gitignore`.
- Never edit these files manually — always regenerate via the training script.
